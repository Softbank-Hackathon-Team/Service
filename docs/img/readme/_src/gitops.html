GitOps 배포 흐름

플랫폼 워커가 승인된 계획을 매니페스트로 찍어 이 레포에 커밋하고, 클라우드는 Argo CD 허브가 밀어 넣고 온프레는 회사 전용 레포로 복사해 고객 클러스터가 안에서 당겨 간다. 비밀값은 레포에 없다.

2gitops 레포 (이 레포)

회사·앱·환경마다 묶음 폴더 하나. 지문이 맞아야 적용된다

tenants/<t-회사>/ argocd/appproject.yaml 회사 울타리 apps/<앱>/<환경>/ plan.json 계획 번호·승인 단계·지문 values.yaml 승인된 Helm 값 manifests/ 찍어낸 결과 bundle.sha256 manifests 지문 platform/appsets/ 환경별 ApplicationSet charts/app/ 세 환경 공통 차트
→
