# 콘솔 프로토타입 (가칭 Kross AI)

상태: AI 초안

이전 한 건의 전체 흐름과 콘솔 화면을 눌러 보며 UX와 구현 범위를 판단하기 위한 프로토타입입니다.
모든 데이터는 예시이고 서버에 연결하지 않습니다. 확정된 UX 문서가 아닙니다.

## 실행

API, DB, Docker, 환경 변수가 필요 없습니다. Node.js만 있으면 됩니다.
이 폴더는 레포의 npm workspace에 속하지 않으니, **이 폴더 안에서** 설치합니다.

```bash
cd prototypes/console
npm install
npm run dev
```

브라우저에서 http://localhost:5180 을 엽니다. 기준 화면은 1440×900입니다.

- `npm run typecheck`: 타입 검사
- `npm run build`: `dist/`에 정적 파일 생성. 해시 라우팅이라 어떤 정적 호스팅에서도 열립니다.

## 화면 이동

- 큰 버튼을 누르면 실제 흐름대로 진행합니다: 로그인 → 대시보드 → 출발 연결 → 읽기와 도착 고르기 → 명세 확정 → 사전 점검 → 계획 승인 → 실행 시작 → 이전 → 롤백 대기 → 정리 → 완료.
- 사람이 결정하는 버튼은 `명세 확정`, `이 계획 승인`, `실행 시작` 세 개입니다. 그 사이는 벤토가 저절로 바뀌며 넘어갑니다.
- 이전이 트래픽 10%에 닿으면 가드레일이 멈춥니다. 에이전트는 수정안까지 제안하고, 적용은 사람이 합니다.
- 상단 버튼으로 대시보드, 환경, 이전, 보안, 감사, 에이전트 화면을 오갑니다. `계정`은 설정·멤버입니다.
- 위쪽 가운데 점선 `프로토타입 화면` 메뉴로 어느 화면이든 바로 갑니다. 거절, 실패, 자동 롤백 같은 예외 화면도 여기서 봅니다. 제품 조작이 아닙니다.
- 화면마다 주소가 있습니다. 예: `#/approve`, `#/paused`

## 구조

```
src/
  design/      토큰과 기본 스타일
  components/
    layout/    3층 뼈대(ConsoleLayout), 벤토 타일(Tile, Hero, StatTile)
    ui/        상태 없는 부품(ActionPill, Checklist, SecurityDot, TrafficBar, Logo 등)
  features/migration/
    flow.ts              화면 목록, 상태 타입, 진행 단계와 롤백 가능 여부 계산
    useMigrationFlow.ts  상태와 화면 이동. 지금은 타이머로 진행을 흉내 냅니다.
    mock.ts              예시 데이터 전부
    screens/             화면. 각 화면 위의 BentoLayout이 그 화면의 모양입니다.
  app/         조립부와 프로토타입 메뉴
```

## 디자인 작업 방식

디자인의 원본은 이 코드입니다. Figma는 업데이트하지 않습니다. 화면과 부품을 여기서 바로 만들어 눌러 보고, 확정한 토큰과 컴포넌트를 `apps/web`에서 가져다 쓰며 서로 계속 맞춥니다.

## 본 제품으로 옮길 때

| 그대로 가져갈 것 | 바꿀 것 | 버릴 것 |
|---|---|---|
| `design/`, `components/` | `useMigrationFlow.ts`의 타이머를 `apps/web`의 폴링(SSE가 생기면 SSE)으로 | `app/PrototypeMenu.*` |
| `features/migration/screens/` | `mock.ts`를 `packages/contracts`의 타입으로 | `flow.ts`의 `presetFor` |

- `components/`는 `features/`를 가져오지 않습니다. 이 방향을 지키면 부품만 따로 옮길 수 있습니다.
- 글꼴은 Pretendard JP 가변 다이나믹 서브셋을 `src/design/fonts/`에 그대로 넣었습니다. 한 글꼴로 한글, 라틴, 가나, 한자를 모두 표시하고 페이지에서 쓰는 글자만 받습니다. 코드와 해시만 IBM Plex Mono입니다.
- 스타일은 CSS Modules와 CSS 변수만 씁니다. 색과 간격은 `design/tokens.css`의 의미 토큰을 씁니다. 임시 로고만 예외입니다.

## 벤토가 움직이는 방식

화면을 옮길 때 `area` 이름이 같은 타일은 View Transitions로 새 자리까지 이어져 움직입니다.
지원하지 않는 브라우저에서는 바로 바뀌고, 동작 줄이기 설정을 켜면 움직이지 않습니다.

## 팀 명세와 다르게 둔 것

검토를 위해 일부러 다르게 만든 곳입니다. 코드 전제를 바꾸는 결정이 아니며, 팀이 정할 사항입니다.

| 항목 | 프로토타입 | 명세·코드 |
|---|---|---|
| 도착을 고르는 시점 | 출발을 읽은 뒤 고르고, 그 자리에서 연결 | `POST /migrations`가 출발과 도착을 함께 받음 |
| Azure | 나머지 환경과 똑같이 고를 수 있음 | 어댑터 모양과 Mock만 |
| 보안 표의 열 | 환경 4개 | 지금 API는 이번 이전의 출발·도착 2개 |
| 롤백 대기 | 2분, 끝나면 자동 정리 | 가이드는 정리 승인, 코드 기본 3초, 요구사항 5분 |
| 예시 수치 | 쓰기 멈춤 3.2초, 복제 지연 0.4초 | 실측은 훨씬 짧음 |
| 가드레일 멈춤 → 에이전트 수정안 제안 → 사람이 적용 → 재개 | 한 흐름으로 이어짐 | 에이전트 점검은 상태 머신과 별개이고 PR 생성은 미구현 |
